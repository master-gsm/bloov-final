HOW IT WORKS NOW
================================================================================

1. FIRST TIME ONLINE
   App starts → IndexedDB init → Initial sync → Download 7 tables to cache

2. READ OPERATION (Offline-First)
   useOfflineData({ table: 'products' })
   ├─ Load from IndexedDB cache immediately
   ├─ If online: refresh from server in background
   └─ Show data instantly (50ms from cache)

3. WRITE OPERATION (Queue-Based)
   executeInsert('sales', data)
   ├─ Generate local ID
   ├─ Cache locally
   ├─ Queue for sync
   ├─ Show UI immediately
   └─ Sync when online

4. BACKGROUND SYNC
   When online: Auto-sync every 30s
   ├─ Process pending operations
   ├─ Handle conflicts (offline-first)
   ├─ Update cache
   └─ Show "All synced" in indicator

QUICK START FOR DEVELOPERS
================================================================================

Using Offline Data in Components:

import { useOfflineData } from '../hooks/useOfflineData';

function MyComponent() {
  const { data, loading, error } = useOfflineData({
    table: 'products',
    fallbackToServer: true,
  });

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error}</div>;

  return (
    <ul>
      {data.map(item => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  );
}

That's it! Automatic offline-first operation.
